# ForeverGold Terminal: спецификация (от «трейдера»)

Тёмный терминал для анализа аукциона WoW: Forever. Веб только анализирует, покупки делаются в игре через аддон. Стек: plain JS и uPlot. Все цены в меди, на экране `12з 34с 56м`, крупные суммы сокращаются до `1.2к з`.

Два правила для всего терминала:
- **У аукциона нет стороны bid.** Есть только лоты на продажу и оценка продаж в день (sales/day). «Объём» везде означает выставленное количество, а не оборот.
- **Чистая выручка** считается как `sell × 0.95 − потерянный депозит`. Без этого вычета прибыль нигде не показывается.

## 1. Раскладка

- **Верхняя панель.** Выбор рынка (ruleset × фракция × регион), свежесть данных («скан 12 мин назад»; жёлтый, если больше 1 ч, красный, если больше 6 ч), поиск по `/` (RU/EN имена, ID), статус демона и аддона.
- **Левая колонка: вотчлист.**
  - Строка: иконка с рамкой цвета качества, имя, `min`, Δ% к вчерашней медиане, спарклайн за 7д, бейдж дней запаса.
  - Цвета: рост зелёный, падение красное. «Дёшево относительно нормы» обозначается отдельным бирюзовым бейджем.
  - Сортировка по любой колонке, навигация ↑↓, по Enter открывается предмет.
- **Центр:** график выбранного предмета.
- **Правая колонка:**
  - стакан из последнего своего скана: цена, количество, накопленное количество, накопленная стоимость выкупа, маркер «медиана 30д», подсветка самого большого разрыва; если скана нет больше 2 ч, стакан серый;
  - ключевые показатели: min, median, p25/p75, median7d/30d, low/high30d, количество, лоты, sales/day, DoS, скидка к 30д, z, волатильность, ликвидность, цена у вендора.
- **Нижние вкладки:** Флипы · Крафт · Сигналы · Распыление · Обзор рынка · Калькулятор · Прогнозы. Таблицы плотные, числа моноширинные, по клику на строку предмет открывается в центре.

## 2. График предмета

- **Тип по умолчанию: линия.** Основной ряд `min` (по нему реально покупаешь), второй ряд `median`.
- **Свечи только там, где их можно построить честно:** дневные свечи по `min` из снимков демона (~15 мин) и точек 24h-истории.
  - O = первый снимок дня, C = последний, H/L = максимум и минимум.
  - Свеча строится при ≥4 снимках за день, иначе ставится точка.
  - По дневным данным 30d/90d свечи не строим, часовые свечи тоже. Подпись: «Свечи по min-buyout из N снимков».
- **Наложения (каждое отдельно):**
  - полоса p25–p75;
  - пунктирные линии median7d / median30d, тонкие линии low30d / high30d;
  - прогноз демона (тренд и полоса 80%) за вертикальной линией «сейчас» с подписью «модель»;
  - ромбы своих сканов;
  - сделки из журнала.
- **Нижняя панель (≈25% высоты):** гистограмма `quantity` и линия `auctions` с подписью «Выставлено, не продажи».
- **Диапазоны:** 24ч · 7д · 30д · 90д. Ось X строго `[now − диапазон, now]`. Шкала Y линейная или логарифмическая.

## 3. Индикаторы

Обозначения: `S = salesPerDay`, `m30 = median30d`.

| Индикатор | Формула | Пороги и цвет | Зачем и что делать |
|---|---|---|---|
| Скидка к 30д | `D = 1 − min/m30` | ≥30% ярко-бирюзовый, 15–30% бирюзовый, <0 серый | Главный показатель для покупки ниже медианы. Покупаем, если D больше 5% плюс запас. |
| Робастный z | `(min − m30)/(1.4826·MAD)` по дневным медианам за 30д | ≤−2 сильный сигнал, −2…−1 слабый | Отделяет аномалию от предмета, у которого цена всегда скачет. |
| Положение в диапазоне | `(min − low30)/(high30 − low30)` | <0.15 низ, >0.85 верх | Дорого сейчас или нет. Выше 0.85 стоит выставлять свои запасы. |
| Дни запаса (DoS) | `qty / S` | <1 зелёный, 1–5 нейтральный, >10 красный | Главный показатель для продажи. При завале не закупаемся. |
| Разрыв над min | `(lvl2 − lvl1)/lvl1` по стакану | >15% подсвечиваем | Одинокий дешёвый лот перед «стеной». |
| Стоимость сдвига цены | `Σ price·qty` ниже цели | в стакане | Сколько золота нужно, чтобы поднять цену до цели (ресет). |
| Моментум | `median7d/m30 − 1` | ±10% стрелка | Тренд недели. Покупка ниже медианы при падении помечается «падающий нож». |
| Волатильность | σ лог-доходностей дневной медианы за 14д | низкая, средняя, высокая | Ширина целевой маржи. |
| Ликвидность | `log10(S·m30)` по шкале 0–100 | — | Флип в предмете, который продаётся раз в неделю, бесполезен. |
| Сезонность | тепловая карта 24×7: `median(min в ячейке)/среднее − 1` | от синего −10% до красного +10%, ячейки с n<3 затемнены | Когда покупать и когда выставлять. |

Цветовое правило: бирюзовый означает «дёшево, покупать», оранжевый — «дорого, продавать», зелёный и красный — только направление цены.

## 4. Скринеры

- **Флипы.**
  - `net/шт = target·0.95 − buy`, где `target = min(m30, median7d)`.
  - Продаваемое количество `min(qty, S·3)`, `EV/день = net·qty_sellable/T_sell`.
  - Падающие ножи (моментум < −10%) по умолчанию скрыты.
- **Крафт:** рецепт, себестоимость, продажа, маржа после 5%, продажи в день, прибыль в день; реагенты раскрываются по строке.
- **Сигналы:** предмет, срабатывает сейчас, число срабатываний и побед, процент успехов с интервалом Уилсона. Если n<10, пишем «мало данных».
- **Распыление:** цена против ожидаемой стоимости материалов после 5%.
- **Обзор рынка:** размер экономики (/v1/economy), лидеры роста и падения, шоки предложения.
- **Прогнозы:** «возможности» демона с пометкой «экспериментально».

## 5. Калькулятор позиции

Входные данные: покупка B, количество q, цель P, срок лота.
- `net = q·(P·0.95 − B)`, ROI = `net/(q·B)`, точка безубыточности `B/0.95`.
- Время продажи `T = (qty_ahead + q)/S`.
- Чувствительность: net при P = m30, median7d, p25, p75.
- Если P выше high30d, предупреждаем «выше всей истории».

## 6. Мало данных: честные состояния

| Сколько есть данных | Что показываем |
|---|---|
| Нет сканов | Пустое состояние с объяснением, без графиков. |
| < 24 ч | Только точки, стакан, min/median, плашка «N сканов за M ч». |
| 1–6 дней | Линия без свечей; показатели 7д/30д «—» с подсказкой; прогноза нет. |
| 7–13 дней | Прогноз с пометкой «низкая уверенность». |
| ≥14 дней | Сезонность (ячейки с n≥3). |

Если скан старше 6 ч, сигналы серые. Первые недели после запуска 5 ноября показываем баннер «цены свежего сервера падают».

## 7. Чего не делаем

- Order flow, ленту сделок, VWAP, bid/ask: данных о сделках нет.
- Внутридневные свечи: ложная точность.
- RSI, MACD, Боллинджер, Фибоначчи: на тонких рядах это шум, z-score, моментум и положение в диапазоне полезнее.
- Шорт, плечо и прочие механики, которых нет в игре.
