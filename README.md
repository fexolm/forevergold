# ForeverGold

Аддон для WoW Forever (клиент 1.60, API 12.x, ретейловский аукцион). Сканирует аукцион, находит лоты дешевле рынка или дешевле цены продажи вендору и выкупает их одной кнопкой.

## Установка (Windows)

1. Склонировать репозиторий куда угодно.
2. В PowerShell из папки репозитория:

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\install.ps1 -AddOnsPath "C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns"
   ```

   Путь к `AddOns` подставьте свой. Скрипт делает ссылку на папку `ForeverGold` (после `git pull` аддон в игре обновится сам), один раз скачивает цены AHledger и ставит задачу в Планировщик, которая обновляет их каждые 30 минут.
3. В игре новые цены подхватываются при входе или по `/reload`.

## Как пользоваться

1. Открыть аукцион, справа появится окно ForeverGold.
2. «Полный скан». Игра разрешает его раз в ~15 минут.
3. В окне список сделок: цена сейчас -> цель (рынок или вендор) и ожидаемая прибыль.
4. Жать большую кнопку. Каждое нажатие делает один шаг: покупает следующий лот, подтверждает покупку ресурса или ищет следующий предмет. Кнопку удобно повесить на клавишу: Настройки -> Управление -> AddOns -> «Следующая покупка».

Купить весь список одним кликом нельзя: игра разрешает одну покупку на одно реальное нажатие. Ресурсы (травы, руда) покупаются нужным количеством сразу у всех продавцов за одно нажатие.

## Настройки

Всё в `ForeverGold/Config.lua`. Главное:

- `RESERVE_GOLD`: несгораемый резерв. Ниже этой суммы аддон ничего не купит. В игре: `/fg reserve 500`.
- `DEAL_MAX_PRICE_RATIO`: покупаем, если цена не выше этой доли рыночной (0.6 = на 40% дешевле).
- `MIN_SALES_PER_DAY`, `MAX_DAYS_OF_SUPPLY`: фильтр ликвидности и сколько штук брать.

Команды: `/fg` (окно), `/fg scan`, `/fg reserve <золото>`, `/fg price <itemID>`.

## Откуда цены

- [AHledger](https://ahledger.com): медиана за 7 дней и продажи в день по рынку `forever.normal.alliance.eu`. Рынок меняется параметром `-Market` у `tools/ahledger-sync.ps1`.
- Свои сканы: дневные минимумы за 14 дней. Используются, если AHledger про предмет ничего не знает.
